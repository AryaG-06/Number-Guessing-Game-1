Number Guessing Game Description:
 A fun number guessing game where players get 3 chances to guess a randomly generated number using hints and their brains! 😍

How to Play:
1. Run the Python program.
2. The computer will randomly choose a number between 1 and 10.
3. You have 3 chances to guess the number.
4. After each guess, you'll get a hint.
5. Try to guess the correct number before you run out of chances!

1. Python
